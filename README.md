# The Fool · 愚者系统

**一个让 AI 陪你玩老游戏的工具。它知道这游戏的全部答案，但会主动闭嘴。**

---

## 它干什么

**一，挡住剧透。**

你什么都能问——这道具留不留、这段能不能跳、我卡住了往哪走、这游戏多长。能答的它当场答，不摆架子。

碰到会毁掉你体验的问题，它不答，但也不糊弄你。它会说"这个我记下了，打完还你"，然后真的记进一个本地文件里。**不是"你自己去发现吧"这种敷衍，是记账，到点兑现。**

**二，补上当年。**

老游戏玩不下去，一半原因不是游戏老，是你缺了当年玩家白送的东西：那年的画面算什么水平、发售前所有人在期待什么、这游戏当时为什么炸、哪些操作在那个年代是常识。它按你的进度一点点喂给你，不是开局倒给你一篇长文。

**三，陪你聊现在。**

打到一半想找人说话——刚才那段对话什么意思、这个角色我看不懂、这游戏到底在干什么——直接问它。

关键是它**只用你已经看到的东西跟你聊**，绝不拿后面的剧情来解释前面。你现在读不懂的，它会告诉你"现在读不懂是正常的"，而不是把答案提前塞给你。

文本量大的游戏尤其吃这个。比如极乐迪斯科那种满屏的概念和典故，你卡在一段对话上想找人聊两句，可身边根本没有正在玩同一段的人。

它也不替你下结论。你想明白的那件事，得是你自己想明白的。

**用起来只有一句话**：跟它说"我想玩血源诅咒"。它会问你一个问题——你已经碰巧知道些什么——然后你就能开了。之后每次回来说一声打到哪了。

**打完的那一刻**，你一路上问过、被扣下的所有答案会一次性还给你；当年发售后的评测、吵架、读者来信，也在那一刻整个对你解锁。你会拿到一个只有走完全程的人才有的视角：**看着当年的人困惑，而你口袋里有答案。**

## 为什么需要它

因为这件事你一个人做不到。

你想查个按键，搜索结果第三条标题就带着结局。你想问朋友一句，他说"我不剧透啊"然后就剧透了。攻略站的页面标题本身就是剧透，你点进去才知道已经晚了。**最麻烦的是你根本不知道哪里有雷**——等你知道的时候，你已经踩上去了。

你需要的是一个知道全部答案、却愿意主动不说的东西。这个角色以前不存在：搜索引擎的职责是尽快告诉你，朋友忍不住，攻略站靠剧透吃饭。

顺带一提，你想玩的那部经典，你已经知道结局了——**不是你想知道的，是它自己漂进你眼睛里的**。等你终于坐下来玩，你不是在体验它，你是在核对答案。

这东西把你放回不知道的那一天。

---

## 为什么叫愚者

塔罗的 0 号牌。牌面上是一个人背着行囊、抬头望天，一只脚已经踏出悬崖边缘，浑然不觉。

那就是没被剧透的玩家的样子：不知道前面是路还是坑，照样走出去。

而且愚者是 0 号——它不在序列里，它在整副牌**之前**。所以这个名字说的不只是"你不知道"，是你被放回了起点之前的那个位置。

## 它长什么样

下面是同一局游戏的三个时刻。

### 开局：卸下

> **你**：我想玩血源诅咒
>
> **它**：血源，2015 年的，好东西。我去把它摸一遍，一分钟。
>
> *（它自己去查了一轮，你什么都没看到）*
>
> **它**：好了。开之前问你一件事——这游戏你之前刷到过什么没？朋友提过的、视频里瞟到一眼的，梗也算，随便倒。魂系别的作品碰过吗？
>
> **你**：玩过只狼。血源就知道很难，还有什么克苏鲁？好像后期会变得很不一样？
>
> **它**：行。
> 那咱这么玩：你就当自己是 2015 年 3 月的人——那会儿全世界都以为这就是个换皮黑魂，这个误会很值钱。
> 说好三件事：后面有什么我不说；你什么都能问，能答的我直接答，不能答的我记着，打完还你；每次回来先说一声打到哪了。
> 进去前给你两样。一，别搜任何角色名加 ending，搜必炸。二，开场那段挫败是设计的一部分，不是你手残。
> 开吧。

注意它没干什么：**你那句"好像后期会变得很不一样"，它一个字都没接。** 没说你猜对了，没说你猜错了，也没夸你"最重要的都没漏"——那句听着像安慰，其实是在告诉你还有更值钱的东西藏着。它只回了一个"行"，然后往下走。

它甚至没纠正你可能记错的东西。你带着一个道听途说的印象进去，被游戏本身推翻——那个瞬间是你的，不该被提前拿走。

三十秒，你回答了一个问题，然后带着比进来时更少的东西上路。开局唯一可见的动作不是给你什么，是让你放下什么。

### 中途：守住

> *（三小时后）*
>
> **你**：等一下，为什么这里的东西会变成这样？跟我一开始看到的完全不一样了
>
> **它**：这个触线了，记下了，通关后还你。
> ——对了，这条线你要是觉得松紧不对，随时能调。
>
> **你**：就说个大概也行
>
> **它**：确定？
>
> **你**：……算了你记着吧。
>
> **它**：记着了。

它不会说"这里有个惊天大秘密我不能说"——那跟直接剧透一样坏，因为它已经告诉你那儿有个大东西了。**它连"这个问题挺关键"都不会说**：只报账，不报货。所以你上面看到的确认只有两个字。

它也只拦你一次。规矩是你定的，你要撕，它确认一遍就给——而且只给你要的那一条，其他的照旧挡着。

### 通关：还账

> *（三周后）*
>
> **你**：打完了
>
> **它**：先说说？
>
> **你**：……（你说了很多）
>
> **它**：那我把欠你的还了。三周前你问过为什么这里的东西会变成这样——现在能说了：（……）
> 另外，当年发售之后吵翻天的那些评论和争论，现在整个对你解锁了。要吗？

这是它存在的理由。所有被扣下的东西都有明确的归还时间，一笔不落。**一个立了扣子不兑现的工具，比一个直接剧透的工具更坏。**

## 什么游戏值得这么玩

不是所有游戏都需要。一个没有表达的游戏，你把信息环境重建得再完美，也不会发生任何事。

值得的大致是两类。

**第一类，有年代的作品。** 这类能吃到全套：既挡住你不该提前知道的，也把当年玩家拥有的东西喂给你——发售前的期待、那个年代的语境、当时人们在争论什么。

| 游戏 | 年份 | 为什么值得这么玩 |
|---|---|---|
| 寂静岭 2 | 2001 | 它的核心是一个必须你自己走完才成立的理解。提前拿到结论，过程就空了 |
| 塞尔达传说 时之笛 | 1998 | 它定义了 3D 冒险游戏的语法，而那些语法今天已经是空气。回到它还是新事物的那一年，才知道当年为什么会炸 |
| 最终幻想 7 | 1997 | 它撞上了整个行业的转折点。不知道后来发生了什么，才能感受到当时的人在为什么激动 |
| 合金装备 3 | 2004 | 它的结局要求你在毫无防备的情况下被击中。知道会发生什么，那一击就落空了 |

**第二类，剧透即毁的作品。** 不一定老，但被剧透一次就永久损失。这类主要用它的守门那一半。

| 游戏 | 年份 | 为什么值得这么玩 |
|---|---|---|
| Outer Wilds | 2019 | 唯一的进度条是你的认知。被剧透的那部分游戏会永久消失，重玩也找不回来 |
| Undertale | 2015 | 它的整个设计假设你是第一次见它。任何形式的预习都会让它对你失效 |
| 极乐迪斯科 | 2019 | 你对主角的判断会随信息一点点重建。顺序被打乱，重建就不成立了 |
| INSIDE | 2016 | 全程无一句台词，理解完全靠你自己拼。别人替你拼好了，就没有可拼的了 |

这份清单会继续长。你想玩的不在上面也没关系——直接把游戏名报给它，它会自己判断有没有当年可回，没有就只做防剧透那半边。

需要一个支持 Agent Skills 的环境。

**Claude Code**

```bash
git clone https://github.com/martinsin0223/the-fool ~/.claude/skills/the-fool
```

**Codex**


**其他环境**：它本质上是一份行为约定，把 `SKILL.md` 整个贴给你的 AI 也能跑起来，只是跨会话记忆会弱一些。

更新：进到目录里 `git pull` 就行。

## 怎么用

开个对话，说一句：

> 我想玩血源诅咒

剩下的它会问你。之后每次回来，说一声打到哪了。

换设备、开新窗口、隔了三周——说"继续玩血源"就能接上，约定和欠你的账都还在。

---

## 它做不到的事

**它会犯错。** 它是个语言模型，不是个滤网。它会尽全力守住，但没有任何机制能保证百分之百不漏。你自己那部分自制力仍然是必需的——它管得住自己的嘴，管不住你的浏览器。

**它造不出动机。** 如果你其实并不想补这个游戏，它帮不了你。它服务的是那种"我错过了它，我想拿回来"的人。

**冷门游戏可能挖不到当年的东西。** 有些游戏当年就没什么声量，它会直接告诉你这块很薄，然后只做防剧透。它不会编造"当年玩家都在猜什么"——宁可承认没有，也不给你假的。

**它不适合没有表达的游戏。** 说白了：一个只是好玩的游戏，用不着这么伺候。

## 关于这东西本身

它不完美，而且我不打算假装它完美。

它是从一次真实的游玩里长出来的，然后被一个不认识它的 AI 从头审过一遍——那轮审查挖出了二十来个问题，其中好几个是自相矛盾：它一边写着"不许形容藏了多大的东西"，一边在另一个文件里把"这笔账挺大"当成正确示范。这些改掉了，但**没被发现的肯定还有**。

守门这件事没有"下次改进"。它漏一次，你就少了一次。

所以两件事想请你做：

**一，别把它当保险箱。** 它管得住自己的嘴，管不住你的浏览器。你自己那份克制仍然是主力。

**二，它做错了就当场骂它。** 挡太死了（你问什么都被记账）、或者说漏了、或者它开始像客服一样说套话——直接告诉它。规矩是你的，你随时能改，它必须听。真觉得这东西该改，也欢迎来 issue 里说。

它更像一份口头约定，不像一个软件。约定的可靠程度，取决于双方。

## 你的数据

所有记录都在你自己机器上：

```
~/.the-fool/<游戏名>/state.md
```

纯文本，随时可以打开看。Claude 和 Codex 共用同一份，换工具接着玩不丢档。

档案本身是零剧透设计的——它只记你问过什么问题、什么时候还，不记答案。**翻自己的档案不会炸伤自己。**

不打算再玩的时候，删掉那个文件夹即可。
