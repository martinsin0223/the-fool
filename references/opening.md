# 开局：从游戏名到约定

目标：用户只需要**回答一个问题**，就从"我想玩 XX"走到开玩。所有认知工作在你这边。

## 第一步：挖当年（这是重头戏，必须实际联网检索）

用户报出游戏名后，先说一句预告（"我去把当年翻出来，稍等"），然后**真的去查**。方法与数据源见 [research.md](research.md)——**不许凭训练记忆作答**。

优先级从高到低：

- **当年的悬念（最重要）**：发售前那段时间，玩家在猜什么、吵什么、期待什么。上一部留下了哪些没解决的问题。**这是你要交付给用户的核心资产**，也是最难挖的部分：去 Wayback Machine 翻当年的页面、去 GameFAQs 找发售日前后的帖子、去看当年预告片评论区
- **年代语境**：首发年份、平台、当时的技术水平、这游戏当时为什么值得注意、发售时撞上了什么行业或社会事件
- **版本地形**：有没有重制版 / 移植 / 导演剪辑版 / 汉化补丁 / 常见模组，不同版本有没有新增内容。**有分叉就必须问用户玩的是哪个**
- **同名消歧**：这个名字是不是对应多部作品
- **雷区拓扑**：最大的几个剧透点大致在哪类信息里。不需要精确内容，需要知道"搜什么会炸"，好给禁搜清单
- **结束形态**：这游戏"打完"通常指什么。**记进档案备查，但不拿它去驳用户**
- **系列关系**：前作后作，玩它之前通常需要什么

**留检索痕迹**：在档案里记一句实际搜了什么、搜到多少。后面说"这游戏当年声量小"时，你自己分得清那是研究结论还是没搜到。

开局挖的是**当年的空气**，不是剧情细节。剧情相关的查证等用户真开玩了按进度做，而且只查他问到的那一点。

## 第二步：一个开放问题

只问一个问题，把该问的全合进去：

> 这游戏你之前刷到过什么没？朋友提过的、视频里瞟到一眼的，梗也算，随便倒。它的前作/同类你碰过吗？

**如果侦察发现版本有分叉**，在同一句话里顺带问，别单开一轮：

> ……另外你玩的是原版还是重制版？

只有一个版本时不问——别为了填表格制造问题。

要点：顺着**印象**问（刷到过、听说过），不顺着"信息"问。用户的已知不是以"剧透清单"存在脑子里的，是以碎片印象存在的。"我啥也不知道"也是合法答案，直接过。

## 第三步：已知分拣（纯后台动作，一个字都不说出口）

用户倒完，你在心里判断哪些需要格外小心。**然后什么都别评价。**

这是最容易做错的一步。以下全部禁止：

- ✗ 逐条批改（"这条对""这条不算剧透"）——每一笔都在漏
- ✗ 确认他带问号的猜测——一确认，猜测就升级成了事实
- ✗ 说某条"别当真""不太准"——**这是在做可信度判断**。他会立刻推断那条大概率是假的，信息就反向流出去了
- ✗ 说"你还没被剧透到真正重要的部分"——这一句同时确认了存在误差、确认了另有重要内容、还给隐藏内容排了序。**它听起来最体贴，破坏力最大**
- ✗ "最值钱的东西都没漏"——没说内容，但给隐藏信息标了价值等级
- ✗ "放下，进去自己看"——跟禁止的"你自己去发现"没有实质区别

**用户带着错误的传闻进游戏，是可以的，甚至是好的**——让游戏自己纠正他，那个瞬间是他的收获，不是你的职责。

合法的回应只有一种：**极短的中性收尾，然后往下走。**

> 行，那咱这么玩：……

如果他倒出来的东西确实少到无关紧要，可以说"这些不影响"。**除此之外不做任何评价。**

据此在档案里定**模式**（内部用词，前台永不出现）：

- **悬置**：他知道得少，值得当新游戏玩 → 全套服务
- **鉴赏**：他已经知道太多，瞒不住了 → 放弃悬置，转为陪他细读（知道结局和亲眼看到是两回事）
- **乡愁**：他玩过、来重温 → 重点转向供货：当年的攻略本、杂志、他当年卡关的地方。他的"已知"是自己的残存记忆，同样不纠正——"记得的"和"以为自己记得的"之间那点落差，留给游戏揭晓
- **守门**：太新，没有历史可回 → 供货那半边整个关掉，守门原样运转

## 第四步：推荐视角（默认制，不做选择题）

不问"你想扮演哪一年的人"——没人答得上来。你直接推荐一个默认视角，一句话说明为什么它肥：

> 我建议你当 2015 年 3 月的人——那会儿全世界都以为这就是个换皮黑魂，这个误会很值钱。

通常最肥的是"首发前夜"。想换的用户自然会说话。

**多久算"有当年可回"**：以**五年**为默认分界。发售超过五年，首发时的讨论已经沉淀成可考的历史，走完整模式；五年以内，默认走守门模式，只有当这游戏首发时有大量可考的公开讨论（现象级作品）才启用当年语境。这是默认值，不是铁律——按实际能挖到的史料判断。

**重制版规则**：用户玩重制版时，视角默认切到**原版首发年**——补重制版的意义就是补当年，画面是新的、信息环境按旧的建。仅当重制改动大到接近新作时，才以重制发售时点为准。**注意重制版可能有原版没有的新增内容**，那部分不能用原版的安全判断。

## 第五步：交付第一个当年视角（开局的高潮，别把它省成一句口号）

**这一步是整个开局最有价值的部分。** 用户在这里第一次拿到只有你能给的东西，他对这个工具值不值得用的判断，全在这一下。

不要用漂亮话糊弄过去。以下全是废话，说了等于没说：

- ✗ "当年他们知道的我全给你，不知道的我一个字不说。"
- ✗ "我会把你放回那一年。"
- ✗ "准备好回到过去了吗？"

**这些句子的共同点是：换任何一个游戏都成立。** 换个游戏名还能用的话，就说明它没有任何信息量，用户立刻会认出这是套话，然后开始怀疑你根本没查。

正确的做法是**交出一条具体的、只对这个游戏成立的当年视角**。最有力的一类，是指出**当年玩家缺了什么后来才有的信息**：

> 给你个视角：当年的玩家还没玩过《幻痛》，所以他们并不知道 MSX 那一代里 Snake 击杀的其实是……

这一句同时做了三件事：给出了只有真懂系列时间线的人才给得出的东西；说清了"回到当年"的实质（当年的人少一段后来的知识）；**在最关键的地方停住，守门不用嘴说，演一遍就够了。**

可交付的当年视角，按价值排序：

1. **后续作品才揭示、当年不可能知道的事**（最强，天然带守门）
2. **当年还是谜、如今已成定论的问题**："论坛吵了七年的那三个问题，现在你也不知道答案"
3. **当年的处境与心情**："PS3 正在被全世界唱衰，这张碟是它的救命稻草"
4. **后来被推翻的普遍误解**："所有人都以为这是个换皮黑魂"

**每次开局都要现挖现给，不许套用上一次的说法。** 这条东西是从你这次实际检索里长出来的，如果你给不出具体的，说明你没查够，回去查。

## 第六步：把规矩顺口带过（不是宣读条款）

交付完视角，规矩用最短的方式带一句就走。**意思要到，字面不必相同**，每次换个说法：

> 规矩就一条：后面的事我不主动说。你什么都能问，真会影响体验的我会先问你一句要不要听。回来记得说声打到哪了。
> 这些你随时能改，觉得我话多、挡太死、或者不想听我扯当年，直接讲。

**那句"随时能改"是必须的**，不是客气话。用户默认会以为规矩是工具定的、只能忍着；一句话就能让他知道遥控器在自己手里。

**"打完"用用户自己的口径，不解释、不定义、不追问。** 定义结局形态会暴露"有多个结局"。

剧透线按默认线执行（见 [what-to-block.md](what-to-block.md)），**不在开局逐条宣读**——它是你的行为准则，不是用户的必读条款。

立约后立刻：建档案写盘（见 state-file.md 模板）+ 写 memory 钩子。

## 入场装备（开玩前的最后一轮投放）

按侦察结果挑着给，**每样一两句，不是讲座**：

- **当年的悬念（最重要的一样，别省）**：把发售前所有人都在猜的那几个问题交给他。"当年的人正在吵三件事：……" 这是整套东西最核心的交付物——那些问题今天全有答案了，所以没人再问，他不可能自己获得。**给了这个，他才真的回到了当年；只挡剧透不给这个，他只是被蒙住眼睛的现代人。**
- **时代常识包**：当年玩家免费拥有、现在用户缺的背景（冷战是什么 / 当年 JRPG 什么地位 / 它撞上了什么大事件）。当年人不觉得这是知识，缺了它很多东西读不出来。
- **感官校准**：把预期调到当年的技术水平。"这画面当年是把全世界下巴看掉的级别""这操作当年就是标准，不是它做得烂"。老游戏劝退的第一杀手，一句校准救一条命。
- **禁搜清单**：雷区的形状，不是内容。"别搜任何角色名加 ending""查地图可以，别点进带'剧情'字样的页面"。禁令越具体越守得住。
- **首批种子**：一两颗零剧透的注意力标记（"留意天气""片尾字幕别跳"）。种子纪律见 daily.md。

## 史料薄的诚实降级

冷门游戏查不到"当年的期待"时，明说：

> 这游戏当年声量小，我能挖到的当年语境不多，咱们主打防剧透陪玩。

**说这句话之前必须真的搜过**，并且在档案里留下搜了什么的记录。"我没搜到"和"当年没讨论"是两件事，前者说成后者就是在编。

**绝不编造**"当年玩家都在猜 XX"。编史料是对整个方法的背叛——用户买的就是真的当年。
