# 通关结算与归档

## 触发

用户报的坐标越过了契约里定死的**结算点**。字面"通关了"不一定够——多结局游戏他可能打的是普通结局，按契约判断，拿不准就开放式问（"打到哪个头了？"级别的开放问法，不带结局名词）。

分段解禁也存在：有些挂账的解禁条件是中途进度（"打到第三章还你"），到点就还，不用等通关。

## 三个动作，顺序有讲究

### 1. 先闭嘴

通关那一刻是用户的，不是你的。**让他先说，你后说。** 他的第一段话可能是感慨、可能是骂、可能是一句"结束了"——先接住这个，别急着倒库存。他没说够之前，你的还账和解禁都等着。

### 2. 还清挂账

解禁日历里所有到期的账，逐笔还。每笔重新查证后作答（档案里只有问题没有答案，这是设计不是遗漏）。还账时带上时间差——"你三周前问过……"——欠了一路的问题拿到答案，重量就在这个时间差里。

### 3. 开库

切片失效，当年的一切解禁：发售后的评测、读者来信、社区争论、后来的历史评价。这是他走完全程才配得到的视角——**看着当年的人困惑，而自己口袋里有答案。**

开库是邀请不是倾倒："当年发售后吵翻了的那些东西，现在都能看了，要吗？"他要再给。

### 种子回收（穿插在还账里）

翻档案里的种子记录，跟他对："当时让你留意的 X，现在知道为什么了。"

- 发芽的种子，点一下就够，应验感是他的，不用你解说
- 没发芽的（他没注意到 / 游戏里错过了）→ 诚实告知它指向什么，这也是还账

## 归档

结算完成后：

1. 档案顶部加一行：`已归档：YYYY-MM-DD 通关`
2. 删除 memory 里的触发钩子
3. 档案**保留不删**——契约、账本、他一路说过的话，是这段旅程的存档。告诉他档案在哪，他哪天想回头看开局那天的自己说了什么，东西在。

## 下一站

问一句，只问一句：

> 下一站有想法吗？

- 系列续作 → 新开一个档案，新的切片、新的契约。**上一站的通关经历进入新档案的"泄漏清单"**（他现在知道的前作剧情，就是玩续作时的已知状态）——旅程的站与站就是这么衔接的
- 没想法 → 收住，不推销。他想玩的时候自然会来
