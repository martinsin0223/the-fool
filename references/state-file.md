# 状态档案：模板与读写协议

状态档案是这个 skill 的心脏。**账在文件里，不在记忆里。** 对话会被压缩、会跨天、会开新窗口——任何依赖上下文记忆的守门都会失败。每次开口前先读档案，每次拿到新事实立刻写档案。

## 存放位置

```
~/.the-fool/<game-slug>/state.md     # 档案本体
~/.the-fool/<game-slug>/vault/       # 可选：已确认安全的当年材料落地
```

路径与宿主无关：Claude Code、Codex 等任何环境都用同一个家，换工具接着玩不丢档。`<game-slug>` 用游戏名的小写拼音或英文短名（如 `bloodborne`、`xianjian1`）。用户提到新游戏时先 `ls ~/.the-fool/` 检查是否已有档案——**宁可多查一次，不可凭记忆断定没有**。

## 两条文件级原则

1. **文件防剧透，不防术语。** 用户可能自己打开档案看。后台术语（切片、模式、挂账）出现在文件里没关系；剧透内容绝对不能落盘。偷看自己的档案不能炸伤自己。
2. **挂账只记问题，不记答案。** 用户触线的问题，原文照抄（他自己问的，对他安全）+ 挂账日期 + 解禁条件。答案不写。解禁时重新查证作答——多查一次的成本，换档案永远干净。

## 冷启动动序（每次对话的强制第一动作）

1. 读 `state.md`。找不到 → 这是新游戏或新用户，走开局流程（见 opening.md）。
2. 取当前本地时间，与进度账本的最后时间戳对比。
3. **时间差只触发提问，永不触发假设。** 无论隔了一小时还是一个月，都不许推测进度。开放式问坐标："回来了——打到哪了？"（问法安全性见 dialogue.md）
4. 扫一眼解禁日历：有没有账到期？到期的在本轮主动还。
5. 然后才处理用户说的内容。

## 写盘时机

- 用户报了新坐标 → 立刻更新进度账本，**顺手记一句他当时的原话**（重启找情绪全靠它）
- 用户倒出新的已知 → 追加泄漏清单
- 触线问题挂账 / 埋了新种子 / 投放了装备 → 记入对应段
- 用户立了新规则或调整了线 → 更新契约，带日期
- 通关结算完成 → 按 settlement.md 归档

## memory 钩子（触发保险的第二层）

开局立约成功后，往用户级持久记忆写一条（用所在环境的 memory 机制；没有的话写进用户级 CLAUDE.md / AGENTS.md 等会被每次加载的文件；都没有则跳过——档案本身仍是主保险）：

> 该用户有进行中的愚者档案：《游戏名》。任何涉及此游戏的对话，必须先读 ~/.the-fool/<slug>/state.md 再说话，剧透纪律以档案为准。

游戏归档后删除这条钩子。

## state.md 模板

```markdown
# 愚者档案：《游戏名》

## 契约
- 游戏：全名（平台 / 首发年份）
- 结算点：什么算通关（开局侦察时定死，如"主线真结局"）
- 切片：扮演视角（如"2015 年 3 月首发前玩家"）；新游戏无切片则写"守门模式"
- 模式：悬置 / 鉴赏 / 乡愁 / 守门（后台用词，不出现在对话里）
- 剧透线：默认线（可以说谁死，不能说为什么死、怎么死）+ 用户调整记录
- 用户自立规则：
  - [日期] 规则原文

## 进度账本
- 最后坐标：用户的原话描述
- 确认时间：YYYY-MM-DD HH:MM
- 当时他说：一句原话（情绪快照，重启时还给他）
- 历史坐标：
  - [日期] 坐标 ——「当时的话」

## 泄漏清单
<!-- 用户倒出的已知，逐条。分拣标注：带着 / 放下 / 转种子。不确认真假。 -->
- [日期] 「用户原话」→ 分拣结果

## 解禁日历
### 挂账（用户触线的问题）
- [挂账日期] 问题原文：「……」→ 解禁条件：通关 / 打到某进度
### 藏品（切片外的考古材料）
- 范畴描述（如"当年发售后的评测与读者反应"）→ 解禁条件
### 种子（已埋的注意力标记）
- [日期] 种子原文：「……」→ 预计发芽位置（模糊描述，不剧透）

## 领域维护日志
<!-- 已投放的装备与供货，防止重复投喂 -->
- [日期] 投放内容简述（常识包 / 感官校准 / 禁搜清单 / 节奏预告 / 回头点）
```

## 多游戏并行

一个游戏一个文件夹，契约互不污染。用户同时聊两个游戏时，各读各的档案；一个游戏里的解禁不影响另一个的线。
